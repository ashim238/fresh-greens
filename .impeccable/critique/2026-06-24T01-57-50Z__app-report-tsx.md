## Anti-Patterns Verdict

## Overall Impression
The layout pass on this screen did the most per change. Three small moves — sentiment groups, chips-before-note, titleBlock collapse — each cut a previously-flagged friction. The screen is now the canonical example of "design serves the contribution" for the project: a calm, plain-language picker that names the sentiment register the user is contributing under, then a detail form that puts the constrained input before the open one. The remaining gaps (no draft, no multi-select sub-tag) are workflow features, not visual ones.

## What's Working
- **Sentiment groups ("Something off / useful / good") in wiltedgreen.** These do three things: (1) name the schema the user is participating in, (2) execute the Wilted-Eyebrow Rule as brand voice, (3) match the calm-companion tone perfectly. This is the one place "labeled groups" earn their keep in the app.
- **Chips before note in detail.** Sub-tag is the constrained input most users will tap; the 280-char note is the free-form input most users will skip. Putting the constrained input first means the modal is "done" sooner.
- **titleBlock collapse from vertical block → single row.** detailTitleRow (32pt glyph + label flex) replaces the 48pt-glyph + label + generic-subtitle stack — exactly the kind of distill move the project's calm-confidence target rewards.

## Priority Issues

- **[P2] No discard-report confirmation on mid-flow X-tap.** A partial-form (sub-tag selected + 100 chars of note + photo attached) discards silently when the user taps X or scrim. **Fix**: confirm dialog only when at least one form field is non-empty. **Suggested command**: `/impeccable harden app/report.tsx`
- **[P2] Sub-tag is single-select where multi-select is the natural model.** "Black-owned" + "Restaurant" + "LGBTQ-friendly" is plausibly all three. **Fix**: switch sub-tag chip behavior from radio to checkbox (per group; tap-active deselects same chip stays). **Suggested command**: `/impeccable onboard app/report.tsx` (sub-tag semantics are arguably an onboarding/contribution-quality question)
- **[P3] identityIcon 56×56 with 32pt SVG inside leaves 24pt dead space.** Standing 2026-06-19 issue. **Fix**: drop wrapper to 32×32 OR bump glyph to 48pt. **Suggested command**: `/impeccable polish app/report.tsx`

## Persona Red Flags

**Jordan (First-Timer)**: Sentiment headers ("Something off / useful / good") do real work for this persona — the previously-flat 6-tile grid forced the user to read 6 labels and infer the category schema. Now the schema is named.

**Riley (Stress Tester)**: Mid-form X without draft preservation is the canonical Riley flag — methodical user partially fills form, navigates away to check something, returns to find it empty. The undo-from-Thank-You is a Riley-class affordance; the missing draft-discard-confirm is the inverse weakness.

## Minor Observations
- `subTagGroup` label uses `subheadlineRegular + labelTertiary` — same register as fieldLabel ("(Optional) Your note"). Felt-welcome category renders multiple labeled groups now; the screen's overall label-tier density is fine but worth a recheck at AX5.
- Thank-You's chevron-back-as-Undo is unconventional iOS; explicit `accessibilityLabel="Undo submission and go back"` mitigates for VoiceOver users but sighted users may still tap it expecting "go back to detail." Documented decision.
