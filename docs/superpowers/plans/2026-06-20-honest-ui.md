# Honest UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the final two Phase 3 fix items — remove the dead static speed-limit sign on `/en-route` (current speed is already shown live above it) and flip the empty contact avatar on `/pulled-over` to outline register so it reads as a CTA instead of a populated identity slot.

**Architecture:** Three atomic commits, two screen files + one docs note. No new dependencies, no new components, no shared-component blast. The fill-vs-outline register flip on the avatar reuses the existing convention established by Button.

**Tech Stack:** React Native + Expo, TypeScript, StyleSheet API. No test runner — verification is `npx tsc --noEmit` (exit 0) + diff inspection + user smoke on a real device.

**Spec:** [`docs/superpowers/specs/2026-06-20-honest-ui-design.md`](../specs/2026-06-20-honest-ui-design.md)

### Task 2: outline register for empty contact avatar

**Files:** `app/pulled-over.tsx`

- [ ] **Step 1: Add the two new styles**

Locate the `contactStyles` block. Find the `avatarCircle:` style entry (around line 2013) and the `contactName:` entry shortly after (around line 2025). Add two new styles immediately after `contactName:` (or alongside `avatarCircle:` — placement is style-block order, choose what reads cleanly):

```ts
  avatarCircleEmpty: {
    // Empty-state register: outline instead of fill (matches Button's
    // outline variant — invitation, not identity). Replaces the
    // wiltedgreen fill with a 2pt freshgreen border. Per Phase 1 P1-11.
    backgroundColor: 'transparent',
    borderWidth: 2,
    borderColor: colors.freshgreen,
  },
  contactNameEmpty: {
    ...typography.bodyEmphasized,
    color: colors.freshgreen,
    textAlign: 'center',
  },
```

- [ ] **Step 2: Apply `avatarCircleEmpty` conditionally in the avatar render**

Locate the avatar render in the contact block (around lines 1097–1100). The current line reads:

```tsx

```

Replace with:

```tsx
<View
  style={[
    contactStyles.avatarCircle,
    !hasContact && contactStyles.avatarCircleEmpty,
  ]}
>
```

- [ ] **Step 3: Flip the `UserPlus` glyph color**

Locate the `UserPlus` render (around line 1108). The current block reads:

```tsx

  size={56}
  color={colors.white}
  weight="duotone"
/>
```

Change `color={colors.white}` to `color={colors.freshgreen}`. (The `UserPlus` only renders in the `!hasContact` branch — a constant swap, no conditional needed.)

- [ ] **Step 4: Apply `contactNameEmpty` conditionally to the contact name**

Locate the contact-name `Text` render at the bottom of the avatar Pressable (around line 1123). The current line reads:


Replace with:

```tsx
<Text
  style={[
    contactStyles.contactName,
    !hasContact && contactStyles.contactNameEmpty,
  ]}

  {displayName}
</Text>
```
